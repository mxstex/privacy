# CLAUDE.md - privacy

Public GitHub Pages site (`main` / root) with the privacy policies of the two Android games.
See README.md.

## Rules

- The policy text belongs to the app repositories: `../gravityAndroid/docs/privacy-policy.md`
  and `../gravityAndroid3d/docs/privacy-policy.md`. Edit it there, never in the HTML here.
- `gravity/index.html` and `gravity3d/index.html` are generated by `build.py`; commit them
  together with the source change that produced them.
- Every push to `main` publishes immediately. Push only a page that `--check` confirms.
- `privacy-policy.html` only redirects to `gravity/`; keep the old URL working.

## Commands

```powershell
python build.py           # render both pages from the app repositories
python build.py --check   # full verification: exit 1 when a page is out of date
```

Standard library only; the app repositories must be checked out next to this one.
